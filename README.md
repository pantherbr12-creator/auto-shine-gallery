# Raja Auto Care Website

Create a modern, responsive website for a fictional car detailing business called "Raja Auto Care".

The website should have:

 A professional homepage with a strong hero section

 Navigation bar with Home, Services, About, Gallery, and Contact

 Hero section with a car-related background image, headline, short description, and "Book Now" button

 Services section with 4 services: Exterior Wash, Interior Cleaning, Ceramic Coating, and Full Detailing

 About Us section

 Before/after gallery section

 Customer testimonials

 Contact section with phone number, email, address, and a contact form

 Footer with social media links

Design requirements:

 Premium automotive aesthetic

 Dark, clean, modern design

 Responsive on mobile, tablet, and desktop

 Smooth scrolling

 Subtle animations

 Clear buttons and good spacing

 Use modern typography

 Make the website look like a real professional business website, not a template

Functionality:

 Navigation links should scroll to the correct sections

 Contact form should have validation

 Book Now button should scroll to the contact section

 Mobile navigation menu should work properly

Use clean, maintainable code and component-based structure where appropriate.
Do not add unnecessary features or authentication.

First build the complete frontend. Do not create a backend or database yet.
